# Assembleur pédagogique de génomes

**Question / objectif :** Implémentation Python de graphes de De Bruijn pondérés, simplification et export de contigs FASTA.

**Candidatures concernées :** Algorithmique, développement Python, bioinformatique ; complément Docker et CI.

**Preuves consultables :** Contribution au scaffold explicitement attribuée, tests de cours et régressions indépendantes, CLI et conteneur.

**Limites :** Projet pédagogique single-end, énumération des chemins peu scalable, pas de validation d’assemblage à l’échelle industrielle.

Consulter le README pour les commandes, l’origine des ressources et les résultats. La présence de tests ou d’une CI ne valide pas à elle seule les conclusions scientifiques.
